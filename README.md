# Noteboard

Noteboard is a fast, lightweight, and touch-first whiteboard and digital note-taking application. It offers multi-page support, smooth pressure-sensitive freehand drawing, smart shapes, text editing, marquee selection, a magic eraser for one-tap object removal, high-resolution image export, and natural iPad pinch-to-zoom at the hand location.

---

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18+ recommended) or [Bun](https://bun.sh/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/noteboard.git
   cd noteboard
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   bun install
   # or
   pnpm install
   ```

### Running Locally

Start the local development server:

```bash
npm run dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🛠 Production Build

To create an optimized production build:

```bash
npm run build
npm run start
```
